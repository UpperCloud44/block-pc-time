# Focus Lock

Таймер фокуса с принудительным отдыхом.

**Цикл:** 30 мин работы → 5 мин блокировки → 30 мин работы → главный экран (кнопки «Начать работу» и «Выйти»).

## Запуск

```
python focus\_lock.py
```

или двойной клик по `run.bat` (запуск без консоли).

Нужен Python 3.8+ с tkinter (входит в стандартную установку для Windows). Зависимости ставить не нужно.

Быстрая проверка цикла (значения в минутах):

```
python focus\_lock.py --focus 0.2 --rest 0.2
```

## Как работает блокировка

* Все открытые окна сворачиваются (Windows API), после отдыха восстанавливаются.
* Поверх всех мониторов показывается полноэкранный экран отдыха с таймером.
* Каждые \~0.7 с экран возвращается на передний план, а новые окна сворачиваются снова.
* Аварийный выход: **Ctrl + Shift + F12**.

## Ограничения

Это программная блокировка: `Ctrl+Alt+Del` и диспетчер задач системой не блокируются. Полная функциональность (сворачивание окон) работает на Windows; на других ОС показывается только блокирующий экран.
